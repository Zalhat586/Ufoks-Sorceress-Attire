## 🛠️ Troubleshooting

### ❌ Outfit Doesn't Appear or Looks Broken
- Ensure PGPatcher has been run after installing all mods.
- Verify the mod is enabled in your load order.
- Check that you have 3BA, CBBE, or UBE installed (at least one).

### 👗 Skirt Doesn't Move
- You need a body physics framework like SMP (HDT-SMP) installed and active.
- Make sure your Skyrim version is SE or AE (not original Skyrim).

### 🎨 Textures Look Glossy or Wrong
- PBR textures require ENB or a PBR-compatible weather mod. If using vanilla, it still looks good, just less realistic.

### 🧩 Conflicts with Other Mods
- Install this mod last in your load order to avoid overwriting conflicts.
